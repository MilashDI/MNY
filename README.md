# MNY · Mafia New Year

Локальная панель ведущего спортивной мафии. Версия 0.1.0.

## Запуск

Откройте терминал в папке проекта и выполните:

```sh
python3 -m http.server 3000 --bind 127.0.0.1
```

Откройте http://localhost:3000. Чтобы остановить сервер, нажмите Ctrl+C.
Также можно открыть index.html напрямую, но для стабильного сохранения используйте один и тот же локальный адрес.

## Порядок работы

1. Добавьте участников в список игроков.
2. Начните партию, выберите десять разных участников и назначьте роли: 6 мирных, шериф, 2 мафии, дон.
3. Ведите речи, выставление, фолы и голосования. Таймер считает вверх и управляется вручную.
4. Ночью отметьте жертву и проверки, затем завершите ночь. Проверки не раскрываются сайтом.
5. Результаты завершённых партий доступны в статистике. Экспортируйте JSON для резервной копии.

Изменения автоматически сохраняются в localStorage текущего браузера. Данные не передаются на GitHub и не синхронизируются между браузерами. Очистка данных браузера удаляет сохранения; используйте экспорт. Одинаковый адрес и порт важны для доступа к прежним сохранениям.

Кнопка отмены возвращает последнее игровое изменение в текущем сеансе. После обновления страницы история отмены очищается. Снятие третьего фола снимает назначенный пропуск речи; возврат удалённого игрока выполняется отдельно.

Повторное равенство разрешается вручную ведущей: поднять всех кандидатов, оставить всех или повторить речи и голосование. Клубные исключения и дополнительные баллы будут добавлены позднее. Статистика включает все сохранённые партии; отдельные вечера пока не группируются.

## Файлы

- index.html — каркас страницы.
- style.css — оформление и адаптация к размерам экрана.
- engine.js — правила и игровые расчёты.
- app.js — интерфейс, сохранение, таймер, история.
- tests/ — проверки игровых правил; запуск: `node --test tests/*.test.cjs`.

Сайт не использует внешних библиотек, шрифтов и сервисов. Опубликован только исходный код; размещение сайта в интернете не настроено.
